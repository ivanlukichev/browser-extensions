## EN (master)

**Name** (≤ 45 chars)
```
HowLoud — Sound Meter
```

**Short description / summary** (Chrome & Edge ≤ 132, Firefox ≤ 250)
```
Measure ambient noise in your browser. A quick decibel estimate from your microphone — nothing is recorded or stored.
```

**Detailed description**
```
HowLoud turns your microphone into a quick, real-time sound level meter — right in your browser, in a single click.

Open the popup, press Start, and watch the estimated decibel level update live, along with the running minimum, average, and maximum for your session. A color-coded scale shows whether the space around you is quiet, moderate, or loud.

WHY YOU'LL LIKE IT
• One-click popup — no page to open, no account, no setup.
• Live dB estimate with min / avg / max for the session.
• Clear noise zones: Very Quiet → Very Loud.
• Works in English, German, and Russian.
• Light, fast, and completely free.

PRIVACY FIRST
HowLoud does not record, store, or transmit any audio. The microphone signal is analyzed in real time, on your device, and discarded immediately. No accounts, no tracking, no data leaves your computer.

GOOD TO KNOW
This is a consumer-friendly estimate, not a certified acoustic instrument. Browsers do not expose true microphone calibration, so the reading is an approximation that varies by device, microphone, distance, and environment. Treat it as a handy reference, not a replacement for a professional SPL meter.

Prefer a native app or a full-screen tool? HowLoud is also available on the web at pickheadphones.com/tools/sound-meter/ and on iPhone (HowLoud — Decibel Meter), with Android coming soon.
```

**Single purpose** (Chrome review field)
```
Estimate the ambient sound level in real time using the device microphone and display it as an approximate decibel value.
```

**Permission justification** (Chrome / Edge review)
```
The extension declares no special permissions and requests no host access. Microphone access is requested at runtime through the standard getUserMedia prompt only after the user presses Start. Audio is processed locally in real time to compute a level estimate and is never recorded, stored, or transmitted.
```

**Firefox — data collection** (AMO required disclosure)
```
This add-on does not collect, store, or transmit any user data. Microphone audio is processed locally and immediately discarded.
```
Manifest already declares `data_collection_permissions.required: ["none"]`.

## DE

**Name**
```
HowLoud — Schallpegelmesser
```

**Short description / summary**
```
Messen Sie Umgebungsgeräusche im Browser. Schnelle Dezibel-Schätzung vom Mikrofon — nichts wird aufgezeichnet oder gespeichert.
```

**Detailed description**
```
HowLoud verwandelt Ihr Mikrofon in einen schnellen Echtzeit-Schallpegelmesser — direkt in Ihrem Browser, mit nur einem Klick.

Öffnen Sie das Popup, drücken Sie Start und beobachten Sie, wie der geschätzte Dezibelwert live aktualisiert wird, zusammen mit dem laufenden Minimum, Durchschnitt und Maximum für Ihre Sitzung. Eine farbcodierte Skala zeigt, ob es um Sie herum leise, moderat oder laut ist.

WARUM ES IHNEN GEFÄLLT
• Ein-Klick-Popup — keine Seite zu öffnen, kein Konto, keine Einrichtung.
• Live-dB-Schätzung mit Min / Mittel / Max für die Sitzung.
• Klare Geräuschzonen: Sehr leise → Sehr laut.
• Funktioniert auf Englisch, Deutsch und Russisch.
• Leicht, schnell und völlig kostenlos.

DATENSCHUTZ ZUERST
HowLoud zeichnet keine Audioinhalte auf, speichert oder überträgt sie. Das Mikrofonsignal wird in Echtzeit auf Ihrem Gerät analysiert und sofort verworfen. Keine Konten, kein Tracking, keine Daten verlassen Ihren Computer.

GUT ZU WISSEN
Dies ist eine verbraucherfreundliche Schätzung, kein zertifiziertes akustisches Instrument. Browser geben keine echte Mikrofonkalibrierung preis, daher ist die Messung eine Annäherung, die je nach Gerät, Mikrofon, Abstand und Umgebung variiert. Betrachten Sie es als praktische Referenz, nicht als Ersatz für ein professionelles SPL-Messgerät.

Bevorzugen Sie eine native App oder ein Vollbild-Tool? HowLoud ist auch im Web unter pickheadphones.com/tools/sound-meter/ und auf dem iPhone (HowLoud — Decibel Meter) verfügbar, Android folgt bald.
